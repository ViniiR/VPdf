this is a PDF converter that can:
    convert 1 or more files into a single PDF
    save such PDF under android's Documents directory
    share the PDF to Android Sharesheet (targeting printer apps)
    --
    this app is also a target of Android Sharesheet
    when presented with 1 or more normal files it can also convert them into a single PDF
    when presented with a single PDF it can only be shared to Android Sharesheet

this is a fun little app to solve a very specific issue, it is only intended for my personal use however it should work in any android 11+ phone
this is also my very first App and Kotlin project i absolutely loved Kotlin and Jetpack Compose and have intentions into developing more in the future
the project lasted about 2-3 days it took so long because i had to learn how to use Android's API
